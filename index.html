Teoría de Compiladores

Cómo un programa escrito por personas se convierte, paso a paso, en instrucciones que una máquina puede ejecutar.

Empezar por el principio Probar el mini compilador
fuente total = precio * cantidad + 5
léxico id(total) = id(precio) * id(cantidad) + num(5)
sintáctico =( total, +( *( precio, cantidad ), 5 ) )
semántico total:int ← int + int ✓
intermedio t1 = precio * cantidad; t2 = t1 + 5; total = t2
máquina mov eax,[precio]; imul eax,[cantidad]; add eax,5; mov [total],eax

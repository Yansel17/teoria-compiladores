Referencias consultadas

Fuentes usadas para elaborar el contenido del portal. Cada entrada indica en qué sección se utilizó. Todos los enlaces abren la fuente original.

Libros y manuales de referencia

  1. Aho, A. V., Lam, M. S., Sethi, R. y Ullman, J. D. (2006). Compilers: Principles, Techniques, and Tools (2.ª ed.). Pearson. https://www.pearson.com/store/en-us/p/compilers-principles-techniques-and-tools/P200000003472 Definición de compilador, modelo análisis–síntesis, fases, código de tres direcciones y el ejemplo posicion = inicial + velocidad * 60. Secciones 1 a 4.
  2. Wikipedia. Compilers: Principles, Techniques, and Tools (el "Dragon Book"). https://en.wikipedia.org/wiki/Compilers:_Principles,_Techniques,_and_Tools Historia de las ediciones del libro. Línea de tiempo, sección 5.
  3. LLVM Project. LLVM Language Reference Manual. https://llvm.org/docs/LangRef.html Características de LLVM IR (SSA, tipado, representación común a todas las fases). Secciones 4 y 5.
  4. Free Software Foundation. GNU Compiler Collection (GCC) Internals: Tree SSA, GIMPLE y RTL. https://gcc.gnu.org/onlinedocs/gccint/ y https://gcc.gnu.org/wiki/GIMPLE Las tres representaciones intermedias de GCC (GENERIC, GIMPLE, RTL). Secciones 2, 4 y 5.
  5. Novillo, D. (2006). An Architectural Overview of GCC. Linux Symposium, Ottawa. https://www.airs.com/dnovillo/Papers/ols2006-slides.pdf GIMPLE como representación de tres direcciones y organización de los optimizadores de GCC. Sección 4.
  6. Microsoft Learn. Managed execution process (.NET). https://learn.microsoft.com/dotnet/standard/managed-execution-process Compilación de C# a CIL con metadatos, verificación y compilación JIT a código nativo. Secciones 2, 4 y 5.
  7. .NET Foundation. The .NET Compiler Platform ("Roslyn"). Repositorio en GitHub. https://github.com/dotnet/roslyn Compiladores de C# y Visual Basic de código abierto con API de análisis. Sección 5.

Apuntes y material universitario

  1. Gutiérrez, J. y González, M. (2008). Compiladores. Grupo de Computadores y Tiempo Real, Universidad de Cantabria. https://www.ctr.unican.es/asignaturas/lan/compila-2en1.pdf Etapas de análisis y síntesis, tabla de símbolos y transformación de la representación en cada fase. Secciones 2 y 3.
  2. Universidad de Guanajuato. Clase digital 5. Análisis léxico: Teoría de los lenguajes. https://blogs.ugto.mx/rea/clase-digital-5-analisis-lexico-teoria-de-los-lenguajes/ Relación entre expresiones regulares, autómatas finitos y la jerarquía de Chomsky. Sección 1.
  3. Universidad de Guanajuato. Clase digital 12. Análisis semántico y estrategias de implementación. https://blogs.ugto.mx/rea/?p=16175 Verificación de tipos y organización de la tabla de símbolos por ámbitos. Secciones 2 y 3.
  4. Sanchis, A., Ledezma, A., Iglesias, J. A., García, B. y Alonso, J. M. Introducción a la Teoría de Autómatas y Lenguajes Formales. OpenCourseWare, Universidad Carlos III de Madrid. https://ocw.uc3m.es/pluginfile.php/2776/mod_page/content/16/tema1_intro.pdf Jerarquía de Chomsky y máquinas abstractas asociadas. Sección 1.
  5. Lambdas Space. Notas de compiladores 02: la fase de análisis. https://lambdasspace.github.io/CMP/notas/cmp_n02.pdf Implementación del análisis léxico con autómatas finitos y construcción del árbol en el análisis sintáctico. Secciones 1 y 3.
  6. Geurts, P. (2014). Intermediate code generation. Curso de compiladores, Universidad de Lieja. https://people.montefiore.uliege.be/geurts/Cours/compil/2013/05-intermediatecode-2013-2014.pdf Posición de la generación de código intermedio como última fase del front-end y tipos de representaciones. Sección 4.
  7. Engineering Hulk. Intermediate Code Generation: Three-Address Code, DAG, Basic Blocks and Control Flow Graph. https://engineeringhulk.com/cs-it/compiler-design/intermediate-code/ Argumento N + M frente a N × M, cuádruplas y triples. Secciones 2 y 4.

Encuestas y artículos sobre compiladores actuales

  2. Analytics Insight (2026). Best Free and Open Source Compilers for Developers in 2026. https://www.analyticsinsight.net/programming/best-free-and-open-source-compilers-for-developers-in-2026 Panorama de GCC, LLVM, Rust y Go como cadenas de herramientas dominantes. Sección 5.
  3. Linux Magazine (2018). GCC, Clang, and MSVC compilers with C++. https://www.linux-magazine.com/index.php/Issues/2018/207/Compilers-and-Standards/(language)/eng-US Clang como front-end y LLVM como back-end; compatibilidad con GCC. Sección 5.

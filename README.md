# Teoría de Compiladores — portal web

Trabajo de investigación en equipo. Portal estático (HTML, CSS y JavaScript sin dependencias) publicado con GitHub Pages.

**Sitio:** https://yansel17.github.io/teoria-compiladores/

## Contenido
1. `index.html` — Portada con los integrantes y datos de la actividad.
2. `compiladores.html` — Definición de compilador y vínculo con la Teoría de Autómatas y Lenguajes Formales.
3. `estructura.html` — Estructura de un compilador (análisis–síntesis, tabla de símbolos, manejo de errores).
4. `fases.html` — Fases del proceso de compilación con un ejemplo seguido de principio a fin.
5. `codigo.html` — Generación de código intermedio y final.
6. `actuales.html` — Principales compiladores empleados en la actualidad.
7. `laboratorio.html` — Mini compilador interactivo (`assets/lab.js`).
8. `glosario.html` — Glosario de términos.
9. `referencias.html` — Referencias consultadas, con enlaces.

## Editar
Los datos de la portada están en `index.html`, entre los comentarios `DATOS DEL EQUIPO`. Los estilos están en `assets/styles.css`.

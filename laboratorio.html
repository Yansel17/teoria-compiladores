Sección 6 · elemento de interés

Laboratorio: un mini compilador en el navegador

Escribe un programa pequeño y compílalo. Cada panel de la derecha corresponde a una de las seis fases estudiadas y muestra exactamente qué entra y qué sale de ella. Los errores aparecen en la fase que los detecta, como en un compilador real.

El lenguaje del laboratorio acepta declaraciones int x = …; y float y = …;, asignaciones x = …;, operadores + - * /, paréntesis, negativos y comentarios //. Las reglas semánticas: toda variable se declara antes de usarse y una sola vez; int se convierte a float automáticamente, pero no al revés.

Ctrl + Enter también compila.

Qué mirar en cada panel

  • Léxico: los tokens, coloreados por tipo. Prueba a escribir @ o 1.2.3.
  • Sintáctico: el árbol. Observa que * queda debajo de + aunque aparezca después en el texto.
  • Semántico: el mismo árbol con el tipo de cada nodo y la tabla de símbolos. Mezcla int con float para ver aparecer inttofloat.
  • Intermedio: código de tres direcciones con temporales t1, t2…
  • Optimización: qué se simplificó y por qué. Escribe (2 + 3) * 4 o x * 1.
  • Generación: ensamblador x86-64 (sintaxis Intel, simplificado): eax para enteros, xmm0 para flotantes.

1 · Análisis léxico caracteres → tokens

2 · Análisis sintáctico tokens → árbol

3 · Análisis semántico árbol → árbol anotado + tabla de símbolos

4 · Código intermedio tres direcciones

5 · Optimización mismo resultado, menos trabajo

6 · Generación de código ensamblador x86-64

Cómo está hecho

El laboratorio es un programa en JavaScript de unas 300 líneas (assets/lab.js) que implementa, de forma simplificada, las mismas técnicas descritas en el portal: un analizador léxico escrito a mano que funciona como un autómata finito, un analizador sintáctico descendente recursivo que sigue la gramática de expresiones de la Sección 1, un analizador semántico con tabla de símbolos y promoción de tipos, un generador de código de tres direcciones, un optimizador con plegado de constantes, simplificación algebraica y propagación de copias, y un generador de ensamblador que selecciona instrucciones distintas para enteros y flotantes.
